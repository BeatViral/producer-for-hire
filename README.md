## Publish with GitHub Pages
1. Open the repository **Settings**.
2. Select **Pages** from the left sidebar.
3. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
4. Set **Branch** to **main** and folder to **/(root)**, then select **Save**.
5. Open the website URL above after GitHub reports the site is published.

The complete site is in `index.html`. No build step, dependencies, paid hosting, or external runtime are required.
